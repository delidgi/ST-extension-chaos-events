# Chaos Plot Twist

Маленькое расширение для SillyTavern, которое иногда подкидывает в чат внезапный сюжетный поворот. Можно настроить шанс срабатывания, отключить ненужные категории и вписать свои события.

Если включить **NSFW protection**, перед событием модель получит просьбу не применять его во время интимной или почти интимной сцены. Это именно инструкция для модели, поэтому результат всё равно зависит от того, насколько хорошо она следует промпту.

## Установка

В SillyTavern откройте **Extensions → Install extension** и вставьте:

```text
https://github.com/delidgi/ST-extension-chaos-events
```

После установки откройте **Chaos Plot Twist** в настройках расширений, выберите категории и выставьте подходящий шанс. Карандаш справа от категории открывает список её событий.

---

## English

A small SillyTavern extension that occasionally throws an unexpected plot twist into the chat. You can adjust the trigger chance, disable categories you do not need, and write your own events.

When **NSFW protection** is enabled, the model is asked not to apply the event during an intimate or nearly intimate scene. It is still just an instruction to the model, so the result depends on how well your model follows the prompt.

### Installation

In SillyTavern, open **Extensions → Install extension** and paste:

```text
https://github.com/delidgi/ST-extension-chaos-events
```

Once installed, open **Chaos Plot Twist** in the extension settings, choose your categories, and set the trigger chance. Use the pencil next to a category to edit its events.
